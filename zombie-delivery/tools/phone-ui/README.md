# Phone UI recorder

Run from `zombie-delivery/`: `python3 tools/phone-ui/check.py /path/to/luau`.

Copies the actual Phone, PhoneContract, PhoneLayout, PhoneRoute, PhonePopup, PhoneApps, PhoneMotion, OrdersUi, TasksApp, StyleApp and shared data into a temporary directory. The fixture supplies narrow service/instance stand-ins, then exercises real construction, server payload updates, action callbacks, resize and lifecycle cleanup. 6.0.1: every app opens in the centred popup and closes back to home (✕, backdrop, Q / ESC / B), and the phone never turns. 6.5: home is six big tiles in order (JOBS, MAP, SHOP, BAG & ITEMS, GARAGE, MORE) and MORE holds CAREER, MISSIONS, CREW, TOP, ESTATE, BANK, MESSAGES and SETTINGS; SHOP's shop list sets the GPS, BAG & ITEMS has its tabs, the messages row counts the unread. 6.12: MORE holds TASKS after CAREER (client/TasksApp.luau): the Tasks remote's state as three daily cards, the bonus card and the weekly card with their progress, rewards and the reset's countdown; CLAIM only on a done task (the gamepad lands on it) and CLAIM BONUS; the rewards waiting on TASKS, MORE and the HUD's phone dot; the toasts and sounds of a task done and a claim paid. 6.12: MORE holds STYLE after TASKS (client/StyleApp.luau, its 3D preview client/StylePreview.luau stubbed and recorded): the COURIER / VEHICLE tabs, a card an item with its price, BUY / WEAR / TAKE OFF through the Style remote, the reasons it can't (a reward, the level, the money), the purchase's sound, the keys (TAB, ↑ ↓, ENTER, L1 / R1) bound only while it is open. 6.12.5: home opens with the MAIN apps (JOBS across, MISSIONS and TASKS under it, red-edged, their live lines and bars: the chapter you are at or why it is shut, NEW on a chapter newly open, the dailies done and the rewards waiting), then six smaller tiles (MAP, SHOP, BAG & ITEMS, GARAGE, STYLE, MORE); MORE keeps CAREER, CREW, TOP, ESTATE, BANK, MESSAGES and SETTINGS; the rewards waiting badge TASKS, not MORE. A warning or failed check stops the command with a nonzero exit code.

This is a behavior check, not a Roblox renderer: fonts, automatic layout, touch hit testing, animation and actual device performance still require Studio. Production files are never rewritten by this tool. The regular required suite additionally runs the pure PhoneLayout regressions and compiles every module at Roblox's `-O0 -g2` settings.
