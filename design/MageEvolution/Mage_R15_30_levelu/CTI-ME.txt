============================================================
Jednotka: Mage (mág) · 30 merge levelů od pravěku do roku 3000
Styl: blocky Roblox low-poly, pouze Part a WedgePart, bez meshí, textur a asset ID.

IMPORT DO ROBLOX STUDIA
------------------------------------------------------------
1. Pravým tlačítkem na ReplicatedStorage (nebo Workspace) → Insert from File… → vyberte .rbxm/.rbxmx.
   Případně soubor přetáhněte myší do okna Studia.
2. Jednotlivé levely: složka modely/. Celá sada: Mage_R15_01-30.rbxm.
3. Žádné skripty, žádné externí assety – model se načte okamžitě a offline.

├─ IntValue Level (1–30)
├─ StringValue UnitType = Mage
├─ StringValue Era (Pravěk / Starověk / Středověk / Průmyslový věk / Moderní doba / Budoucnost)
└─ StringValue Appearance (český popis vzhledu)

KONVENCE
------------------------------------------------------------
• Postava stojí chodidly přesně na y = 0 a dívá se do −Z (LookVector = 0, 0, −1).
• Všechny díly mají CanCollide = false, CanTouch = false; výbava Massless = true.
• Hůl: osa hole prochází středem pravé pěsti (RightHand), prsty pěsti ji obepínají.
  Krystal hole je samostatný Neon díl „Crystal“ s PointLight. Od levelu 11 kolem hlavice
  levitují krystaly nebo runy (díly Float*), pevně přivařené k holi.
• Póza držení hole a předmětu je zapečená v C0 kloubů ramen/loktů – standardní R15
  animace (idle, walk) běží nad ní přes Motor6D.Transform.
• Pro pohyb jednotky nastavte HumanoidRootPart.Anchored = false.
• Svítící oči od levelu 20 (Neon), výraz obličeje se mění od zvědavého učně po přísného arcimága.

POUŽITÍ V MERGE HŘE (ukázka Luau – do vlastního skriptu, model žádný skript neobsahuje)
------------------------------------------------------------
local folder = game.ReplicatedStorage:WaitForChild("Mage_R15_01-30")
local function spawnMage(level, cframe)
    for _, m in folder:GetChildren() do
        if m:FindFirstChild("Level") and m.Level.Value == level then
            local unit = m:Clone()
            unit:PivotTo(cframe)   -- pivot = HumanoidRootPart
            unit.Parent = workspace
            return unit
        end
    end
end
